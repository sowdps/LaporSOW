# LAPOR SOW

## Sistem Laporan dan Permintaan Teknisi IT

LAPOR SOW adalah sistem berbasis web untuk melakukan pelaporan kendala IT,
permintaan teknisi/SOW, monitoring proses pengerjaan, serta rekapitulasi laporan.

---

## Fitur Utama

### 1. Form Order SOW
User dapat membuat laporan/order dengan data:

- Nama
- NIP
- Kode Cabang
- Jenis Kendala
- Deskripsi
- Nomor WhatsApp
- Data pendukung lainnya

Setiap laporan mendapatkan Kode Order SOW secara otomatis.

---

### 2. Dashboard Admin

Admin dapat melihat seluruh order dan melakukan monitoring:

- Total Order
- OPEN
- PROSES
- SELESAI
- Pencarian Kode Order
- Filter Cabang
- Filter tanggal
- Detail Order

---

### 3. Manajemen Teknisi / SOW

Admin dapat:

- Melihat daftar teknisi
- Menambah teknisi
- Mengubah nama teknisi
- Mengaktifkan teknisi
- Menonaktifkan teknisi
- Menentukan teknisi pada order
